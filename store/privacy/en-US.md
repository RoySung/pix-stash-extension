# PixStash Privacy Policy — Draft

Publication status: draft. Developer: RoySung. Contact: roysunghan@gmail.com. Effective date: date of first public publication (fill in before publishing).

PixStash is provided by RoySung to help you save web images and screenshots and organize references with folders, tags, and notes.

## Information processed

When you open the collection interface or use capture features, PixStash may read the active page title, URL, website name, candidate image URL, and image source type. Saved library items include images or screenshots, previews, source information, capture time and mode, dimensions, and the folders, tags, and notes you add. Screenshots contain the selected region or visible viewport.

PixStash also stores preferences such as language, library view, and image display size. This information supports capture, organization, search, preview, and revisiting sources.

## Local storage

The library is stored in the extension storage area of your current browser profile. Preferences use browser-local storage mechanisms. PixStash currently has no account system, developer-hosted cloud library, or cross-device synchronization, and does not upload your library to a developer server as part of its service.

## Requests to websites

Saving a web image requests the image from its website or image host. If conversion to a local image fails, some collection flows may retain the original image URL. Displaying that item later may request the image from its source again. Clicking a source link opens that website in your browser.

These sources may receive your IP address and ordinary network request information and process them under their own policies. Local storage does not mean that every operation is offline.

## Analytics, advertising, and sharing

The current version has no developer-provided usage analytics, advertising, or tracking service. It does not send library contents or usage logs to the developer or sell library contents. Requests to external image hosts and source pages operate as described above.

## Retention and deletion

Data remains in your browser profile until you delete it or the browser removes the relevant extension data. You can delete individual or selected library items. Deleting a folder removes its organizational associations, not the images themselves; other folder associations remain.

To remove all local extension data, use your browser's extension data controls or uninstall the extension. Clearing data, uninstalling, or reinstalling may result in library loss. There is currently no built-in cloud backup or recovery guarantee. Do not use the library as your only backup of important content.

## Contact and changes

For data handling questions, contact roysunghan@gmail.com. Updates will be published on this page with an updated effective date. This policy covers the PixStash extension; external websites follow their own policies.
